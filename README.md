# 비밀노트

과목별 공부 자료를 모아 휴대폰에서 조용히 복습하는 정적 웹앱입니다.

## 사용

- 과목을 만들고 문답, 4지선다, 일반 노트를 입력합니다. 객관식은 각 보기의 설명을 따로 저장합니다.
- 복습 화면을 터치하면 답과 모든 보기 설명이 나오고, 다시 터치하면 다음 노트로 이동합니다.
- 숨김을 누르면 검은 화면이 됩니다. **두 번 빠르게 터치**하면 돌아옵니다.
- 과목별 PDF를 추가하면 페이지 단위로 글자를 추출합니다. 검색 결과에서 원문 페이지를 열거나 노트로 저장할 수 있습니다.
- 의미 검색을 선택하면 다국어 MiniLM 모델을 다운로드해 **기기 안에서** 검색합니다. PDF·질문·추출한 글자는 외부 서버에 전송하지 않습니다. 모델 파일 다운로드에는 CDN 및 Hugging Face 접속이 필요합니다. 최초 색인 생성은 문서 크기와 폰 성능에 따라 오래 걸릴 수 있습니다. 관련 원문을 찾는 검색이며 AI 답변 생성 기능은 아닙니다.
- 모델을 불러오지 못하면 실패 안내 후 단어 검색으로 동작합니다.
- PDF 업로드는 파일당 50MB까지 지원합니다. 직접 추가한 PDF의 OCR과 여러 기기 동기화는 미지원입니다. 기본 교재는 이미지 글자를 미리 읽어 색인에 포함합니다.

## 기본 교재와 실습 자료

사용자가 공개 탑재를 승인한 자료를 과목별 `library/*/catalog.json`에서 제공합니다.

| 과목 | PDF 수 | 페이지 | 범위 |
| --- | ---: | ---: | --- |
| AI기초와활용 | 14 | 258 | 1~7주차 각 2강 |
| 공학생을위한실용AI | 14 | 275 | 1~7주차 각 2강, `sales.csv` 별도 |
| 반도체패키지공학실무 | 7 | 315 | 1~7주차 |
| 응용수리실무 | 14 | 226 | 1~7주차 각 2강 |
| 전자응용회로설계 | 18 | 246 | 1~6주차 각 3강; 7주차 PDF 없음 확인 |
| 컴퓨터활용실무 | 7 | 241 | 1~7주차 |
| 프로그래밍언어(Ⅱ) | 7 | 210 | 1~7주차 |
| 합계 | 81 | 1771 | CSV 1개 별도 |

응용수리실무의 1주차 1·2강 `(1)` 파일은 SHA-256으로 원본과 완전히 동일한 것을 확인하고 등록에서 제외했습니다. 원본 파일은 작업용 첨부파일 위치에 유지합니다. 표시 이름에서 분반·교수명·버전·촬영용 표시를 빼고 주차·강의 순서를 정리했습니다. 전자응용회로설계의 `5_1.pdf` ~ `6_3.pdf`는 PDF 내부 표지를 확인해 이름을 정리했습니다.

`판매 실습 데이터 sales.csv`에는 Date, Menu, Quantity, Price 네 열과 데이터 24행이 있습니다. 표 보기, 행 단위 검색, 출처 행 표시, 검색 결과 노트 저장, 원본 다운로드를 지원합니다. 셀 내용은 HTML로 실행하지 않고 글자로 표시합니다. CSV는 기본 제공 실습 자료이며 직접 추가하는 파일 선택 기능은 PDF 전용입니다.

원본 PDF는 페이지를 열 때 내려받고, 검색 색인은 미리 추출합니다. 이미지가 많은 페이지는 Tesseract의 한국어·영어 OCR 결과를 함께 색인에 넣습니다. OCR 결과는 검색에서 ‘이미지 글자 · 원문 확인’으로 표시합니다. 띄어쓰기 차이는 단어 검색에서 보정하고, 같은 페이지의 여러 구간은 검색 결과에서 중복하지 않습니다. 수식·회로도·코드·작은 글자는 잘못 인식될 수 있으므로 원문을 확인해야 합니다. 원본 PDF의 내용은 변경하지 않습니다. 직접 추가한 PDF에는 OCR을 실행하지 않습니다.

교재는 과목별로 한 번 등록하고, OCR 색인 업데이트는 기존 기본 교재의 색인만 갱신합니다. 기존 노트·직접 추가한 PDF·삭제한 교재 목록은 유지합니다. 처음부터 삭제한 과목도 색인 업데이트 때문에 다시 생기지 않습니다. 이후 버전에서 새 자료를 추가할 때는 카탈로그와 로더의 목표 버전을 함께 변경해야 합니다.

### OCR 색인 재생성

PyMuPDF, `pdftotext`, Tesseract 및 공식 `tessdata_fast`의 `kor.traineddata`, `eng.traineddata`를 준비합니다. 검증된 현재 환경의 언어 모델은 `/workspace/.cache/secret-note-ocr/tessdata`에 보관합니다. 도구와 모델은 공개 사이트 실행에는 필요하지 않습니다.

```sh
python3 scripts/ocr-library.py --tessdata-dir /workspace/.cache/secret-note-ocr/tessdata --workers 4
```

현재 기기의 CPU 할당은 4개이므로 4개의 분리된 프로세스로 처리합니다. `OMP_THREAD_LIMIT=1`을 사용해 추가 스레드를 제한합니다. OCR 작업은 `/workspace/.cache/secret-note-ocr/pages-v2`에 페이지별로 보관해 중단 후 다시 실행할 수 있습니다. 하나라도 실패하면 카탈로그를 저장하지 않고 오류를 보고합니다. 모든 작업이 끝나면 완성한 파일로 교체합니다. 이미 OCR을 완료한 카탈로그는 다시 처리하지 않습니다. 신규 자료나 처리 방식을 바꿀 때 해당 카탈로그의 `ocrVersion`을 제거하고 새로운 캐시 경로를 사용하세요.

시험 후 제거 요청 시 공개 PDF·CSV·추출 색인과 Git 기록, 브라우저의 IndexedDB·서비스 워커 캐시를 함께 점검해야 합니다. 사이트 파일만 삭제해도 기존 다운로드나 Git 기록의 복사본은 남을 수 있습니다. 자동 삭제나 시험 날짜 표시는 없습니다.

## 저장과 오프라인

노트, 검색 색인과 직접 추가한 PDF는 브라우저의 IndexedDB에 저장됩니다. 기본 교재 원본은 사이트에서 제공되며, 열어본 파일은 서비스 워커 캐시에 보관될 수 있습니다. 기기·브라우저·사이트 주소마다 별도 저장소입니다. 시크릿 모드, 사이트 데이터 삭제, 브라우저의 저장 공간 정리로 사라질 수 있습니다.

백업 JSON에는 **과목과 노트만** 포함됩니다. PDF와 검색 색인은 포함되지 않으므로 PDF 원본은 별도로 보관하세요. 복원은 기존 자료를 유지하고 백업 과목을 추가합니다.

처음 온라인으로 앱을 열어 서비스 워커 준비가 끝나면 노트 복습을 오프라인에서 사용할 수 있습니다. 의미 검색의 오프라인 동작은 모델·실행 도구의 캐시 상태에 따라 달라지며 보장하지 않습니다. PDF의 글꼴 자원은 첫 열기 때 로드되므로 처음 여는 PDF는 온라인 사용을 권장합니다.

## 개발과 배포

빌드나 패키지 설치가 필요 없습니다. 기존 체크아웃에서 실행합니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포합니다. 스크립트와 자산은 상대 경로를 사용합니다. 캐시 구성이 바뀌면 `sw.js`의 캐시 버전을 변경하세요.

PDF.js 4.10.38의 라이선스는 `vendor/PDFJS-LICENSE`에 포함되어 있습니다. 모델과 Transformers.js는 별도 배포자의 라이선스가 적용됩니다.
