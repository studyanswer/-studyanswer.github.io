# 비밀노트

과목별 공부 자료를 모아 휴대폰에서 조용히 복습하는 정적 웹앱입니다.

## 사용

- 과목을 만들고 문답, 4지선다, 일반 노트를 입력합니다. 객관식은 각 보기의 설명을 따로 저장합니다.
- 복습 화면을 터치하면 답과 모든 보기 설명이 나오고, 다시 터치하면 다음 노트로 이동합니다.
- 숨김을 누르면 검은 화면이 됩니다. **두 번 빠르게 터치**하면 돌아옵니다.
- 과목별 PDF를 추가하면 페이지 단위로 글자를 추출합니다. 검색 결과에서 원문 페이지를 열거나 노트로 저장할 수 있습니다.
- 의미 검색을 선택하면 다국어 MiniLM 모델을 다운로드해 **기기 안에서** 검색합니다. PDF·질문·추출한 글자는 외부 서버에 전송하지 않습니다. 모델 파일 다운로드에는 CDN 및 Hugging Face 접속이 필요합니다. 최초 색인 생성은 문서 크기와 폰 성능에 따라 오래 걸릴 수 있습니다. 관련 원문을 찾는 검색이며 AI 답변 생성 기능은 아닙니다.
- 모델을 불러오지 못하면 실패 안내 후 단어 검색으로 동작합니다.
- PDF 업로드는 파일당 50MB까지 지원합니다. 스캔본 OCR, 여러 기기 동기화는 미지원입니다.

## 기본 교재

사용자가 제공한 AI기초와활용 1~7주차 각 1·2강, 총 14개 PDF(258페이지)를 `library/ai-basics`에서 공개 제공합니다. 원본은 사용자가 공개 탑재를 승인했으며, 검색용 글자는 미리 추출해 `catalog.json`에 저장했습니다. 새로 열거나 이전 버전에서 업데이트하면 교재 목록을 한 번만 추가합니다. 이미 같은 이름으로 보관한 PDF는 유지하고, 사용자가 삭제한 기본 교재는 새로고침으로 다시 생기지 않습니다.

교재 원본은 페이지를 열 때 다운로드합니다. 직접 추가한 PDF는 기존대로 이 기기에만 보관합니다. 파일명에 있던 ‘촬용’은 표시 이름에서 ‘활용’으로 정리했습니다. 이미지 내부의 글자는 검색 색인에 포함되지 않을 수 있습니다.

시험 후 제거 요청 시 공개 PDF·추출 색인과 Git 기록, 브라우저의 IndexedDB·서비스 워커 캐시를 함께 점검해야 합니다. 사이트의 파일만 삭제해도 기존 다운로드나 Git 기록의 복사본은 남을 수 있습니다. 자동 삭제나 시험 날짜 표시는 없습니다.

## 저장과 오프라인

노트, 검색 색인과 직접 추가한 PDF는 브라우저의 IndexedDB에 저장됩니다. 기본 교재 원본은 사이트에서 제공되며, 열어본 파일은 서비스 워커 캐시에 보관될 수 있습니다. 기기·브라우저·사이트 주소마다 별도 저장소입니다. 시크릿 모드, 사이트 데이터 삭제, 브라우저의 저장 공간 정리로 사라질 수 있습니다.

백업 JSON에는 **과목과 노트만** 포함됩니다. PDF와 검색 색인은 포함되지 않으므로 PDF 원본은 별도로 보관하세요. 복원은 기존 자료를 유지하고 백업 과목을 추가합니다.

처음 온라인으로 앱을 열어 서비스 워커 준비가 끝나면 노트 복습을 오프라인에서 사용할 수 있습니다. 의미 검색의 오프라인 동작은 모델·실행 도구의 캐시 상태에 따라 달라지며 보장하지 않습니다. PDF의 글꼴 자원은 첫 열기 때 로드되므로 처음 여는 PDF는 온라인 사용을 권장합니다.

## 개발과 배포

빌드나 패키지 설치가 필요 없습니다. 기존 체크아웃에서 실행합니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포합니다. 스크립트와 자산은 상대 경로를 사용합니다. 캐시 구성이 바뀌면 `sw.js`의 캐시 버전을 변경하세요.

PDF.js 4.10.38의 라이선스는 `vendor/PDFJS-LICENSE`에 포함되어 있습니다. 모델과 Transformers.js는 별도 배포자의 라이선스가 적용됩니다.
